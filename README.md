# HR Attrition & Workforce Analytics Dashboard

A comprehensive HR analytics solution built in **Microsoft Power BI** to monitor workforce demographics, employee performance, compensation structures, and retention metrics.

## Project Overview
This project provides data-driven insights into employee distribution, departmental diversity, compensation trends, and performance evaluations. It is designed to help HR leaders and management track key workforce KPIs, understand attrition factors, and optimize talent management.

---

## Key Performance Indicators (KPIs)
* **Total Employees:** 417
* **Average Age:** 43 years
* **Average Monthly Salary:** $492 (base metric)
* **Average Performance Score:** 3.02 / 5.0
* **Active Employee Rate:** 49%

---

## Dashboard Structure & Visuals
1. **Demographics:** Age group distribution, gender diversity by department, and average age breakdown.
2. **Performance Analysis:** Departmental performance scores and performance distribution across experience levels (Senior, Mid, Junior).
3. **Compensation Analysis:** Total salary distribution across departments (IT, Sales, HR), salary vs. performance correlations, and average bonuses by experience tier.
4. **Trend & Geographic Analysis:** Historical employee joining trends over time, yearly salary increase percentages, and geographic mapping of employee distribution across locations.

---

## Tech Stack & Skills Demonstrated
* **Tool:** Microsoft Power BI Desktop (`.pbix`)
* **Data Preparation & Modeling:** Cleaning datasets, establishing relationships, calculated columns, and DAX measures.
* **Data Visualization:** Designing clean, modern corporate dashboards with customized background layouts and clear metric cards.
* **Data Source:** Structured employee dataset (`Employee_dataset.csv`).

---

## How to View the Project
1. Clone the repository or download the `.pbix` file.
2. Open the file using **Microsoft Power BI Desktop**.
3. Explore the interactive filters (Department, Gender, Age Group, Experience Level, and Status) to slice the workforce data dynamically.
